# Support

Hi! This is a community-maintained fork of
[bevinkatti/PdfZero](https://github.com/bevinkatti/PdfZero). Here's where to
find help.

## Documentation

* **[README](README.md)** — features, setup, architecture, and roadmap.
* **[CONTRIBUTING](CONTRIBUTING.md)** — dev setup and project conventions.
* **[SECURITY](SECURITY.md)** — how to report vulnerabilities.

## How to get help

| I want to… | Where to go |
|---|---|
| Report a bug | [Open an issue](https://github.com/zademy/PdfZero/issues) — include browser, OS, steps, and a sample PDF |
| Request a feature | [Open an issue](https://github.com/zademy/PdfZero/issues) with your use case |
| Ask how something works | [README → Architecture](README.md#architecture), or open an issue labeled as a question |
| Report a security problem | [SECURITY.md](SECURITY.md) — private reporting only, no public issues |
| Contribute code | Read [CONTRIBUTING.md](CONTRIBUTING.md), then open a PR |

## Before you file an issue

1. Make sure you're on the latest version (`main`).
2. Try a hard refresh / different browser — some bugs are worker/cache related.
3. Search existing issues to avoid duplicates.

Thanks for using PDFZero! If it helps you, a ⭐ on both
[this fork](https://github.com/zademy/PdfZero) and
[the original](https://github.com/bevinkatti/PdfZero) is appreciated.
